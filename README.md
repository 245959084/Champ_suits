# League of Legends Champions Recommendation
This tool looks for champions that suit users based on their preference. All users have to do is to pick the style they want to chose.

## Usage
User first need to get on to streamlit with "uv run streamlit run main.py". Then, all you have to do is make a choice from the options given to you. The user will receive an error message if there is no champion that fits all of their preferences. Once the user reaches the end, the tool will display champions that match their preferences, along with images that help the user quickly identify the champions in the game.
